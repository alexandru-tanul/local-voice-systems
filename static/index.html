            What this check inspects
            

              

                

                  Software environment
                  
The dashboard Python runtime, GPT-SoVITS files in WSL, the speech-recognition environment and model cache, and the global push-to-talk helper.

                

                

                  Models and GPU
                  
Counts GPT and SoVITS checkpoints, then asks PyTorch inside WSL whether GPU acceleration is available and which GPU it sees.

                

                

                  Audio devices
                  
Briefly requests microphone permission, closes the stream at once, and lists microphone, output, and VB-CABLE devices. No audio is recorded or saved.
